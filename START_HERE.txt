                          HOW TO GET STARTED
================================================================================

STEP 1: Install Dependencies (1 minute)
  $ pip install -r requirements.txt

STEP 2: Generate Keys (30 seconds)
  $ python setup.py

STEP 3: Start Proxy (30 seconds)
  $ python main.py
  
  You should see:
    ✓ Keys already exist
    ✓ Jailbreak patterns created
    ✓ Inspection API thread started
    ✓ Proxy running on localhost:8080
    ✓ Inspection API on localhost:8081

STEP 4: Point Your LLM Client (30 seconds)
  $ export HTTP_PROXY=http://localhost:8080
  $ export HTTPS_PROXY=http://localhost:8080

STEP 5: Use Normally (seconds)
  from openai import OpenAI
  client = OpenAI()  # Will route through proxy
  response = client.chat.completions.create(...)

STEP 6: Monitor (realtime)
  $ curl http://localhost:8081/stats
  
  Example response:
  {
    "statistics": {
      "total_requests": 5,
      "intent_distribution": {"user_turn": 5},
      "sensitivity_distribution": {"low": 5},
      "pii_hits": 0,
      "avg_tokens_per_request": 125
    }
  }
